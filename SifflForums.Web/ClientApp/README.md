# ClientApp

Angular 22 front-end for Siffl Forums.

## Development server

Run `npm start` (`ng serve`) for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files. The API root is configured in `src/environments/environment.ts`.

## Build

Run `npm run build` to build the project. The build artifacts will be stored in the `dist/ClientApp/browser` directory.

## Running unit tests

Run `npm test` (`ng test`) to execute the unit tests with [Vitest](https://vitest.dev/).
